# Canario

Signed and notarized macOS builds of Canario, a browser-shaped terminal.
Apple silicon only.

**[Download the latest Canario.dmg](https://github.com/canarioterm/releases/releases/latest/download/Canario.dmg)**

Every release is built, signed and notarized by CI; `checksums.txt`
alongside each DMG carries its SHA-256. Canario itself is not open
source; this repository exists to host releases and track issues.
